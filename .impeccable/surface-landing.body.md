# Surface thesis

The landing surface shows one connected signal path from calendar detection to interview readiness. It refuses the generic dashboard-grid default. The first viewport uses an editorial left narrative and a live wayfinding instrument on the right.

## First viewport

- Floating navigation with one polished primary action.
- Pill, sentence-case headline, concise promise, two actions.
- Connected calendar → detection → interview → readiness → practice route.
- Gold is concentrated on the current route, primary action, and earned score.

## Continuation

Sections each prove one part of the loop through a bespoke visualization: calendar detection, context synthesis, live interview, analysis, and improvement. Copy stays concise and every section terminates in a next action.

## Responsive rule

On mobile the route becomes a vertical stepped instrument below the copy; it is not a stack of detached cards.
