# Intervu AI implementation plan

## Phase 1 — foundations

- workspace, environment contract, Docker services
- Next.js and FastAPI boot paths
- tokens, typography, primitives, fixture domain data
- SQLAlchemy metadata, Alembic baseline, health checks
- Firebase verifier and development principal

## Phase 2 — product loop

- interview CRUD and rounds
- calendar OAuth/sync architecture and deterministic detection
- resume/JD upload, parsing contracts, role-match calculation
- preparation plan and task workflows

## Phase 3 — adaptive practice

- mock provider, OpenRouter provider, specialized agents
- session state machine and persistence
- typed WebSocket gateway/client
- microphone visualization, transcript flow, adaptive follow-ups

## Phase 4 — evidence and improvement

- answer evaluation and retry-weak-answer flow
- deterministic speech metrics and weighted reports
- topic performance, readiness, trends, analytics
- notifications, settings, privacy actions

## Phase 5 — launch hardening

- loading/empty/error/recovery states
- ownership, rate limits, request IDs, secret-safe logging
- unit/service/API/UI/browser tests
- responsive and accessibility audit
- production builds, migration check, documentation
